# Target-Root Archives

**Path**: `internal/artifact/archive/` — deterministic release archive creation
**Parent**: `internal/artifact`
**Submodules**: none (leaf)

## Purpose

This module archives current target-native output roots for the public `package` operation. It does not compile, write generated output, or include compiler-owned provenance and repository-root compatibility files.

## Functional Responsibilities

- Validate archive metadata and target output roots.
- Read files from `TargetPlan.Files` bytes and `ArchiveUnits`; no filesystem walk of generated output.
- Emit deterministic `.tar.gz` archives, with the Pi `.tgz` suffix.
- Preserve an existing archive when the generated bytes are unchanged.

## Subdomain Classification

**Supporting.** Archive format and release layout are stable output concerns with moderate platform and tooling volatility.

## Public Contract

```text
WriteTargetRoots(workspace-root, SourceManifest, BuildPlan, archive-output) -> [ArchivePath] + error
```

The input plan is already validated and current. Each archive contains one target's native output root at archive root. Compiler provenance, repository-root compatibility files, symlinks, and non-regular files are excluded or rejected.

## Integrations

- **Counterpart**: `internal/artifact`
  - **Direction**: the artifact facade validates the plan and exposes archive errors as diagnostics.
- **Counterpart**: `internal/compiler/model`
  - **Direction**: consumes manifest output/distribution metadata and target plans.
  - **Shared knowledge**: relative output, target identity, and planned native files only.

## Constraints and Invariants

- `distribution.name` is validated as a safe filename basename before the output directory is created: no path separators, no null bytes, not `.` or `..`, not a Windows-reserved device name. Validation runs before `os.MkdirAll` to prevent partial directory creation for invalid inputs.
- After computing each archive path, containment within the requested output directory is verified via `filepath.Rel`; a name like `../evil` that escapes the output directory is rejected.
- Archive bytes do not depend on clock, hostname, absolute paths, locale, or filesystem traversal order.
- Archive paths are relative to the target root and sorted.
- Existing archives are not replaced when their bytes match the newly generated archive.
- The module does not import the compiler, target adapters, compatibility, process, network, or vendor configuration behavior.

## Test Specification

- Every target root is archived with the expected suffix and entries.
- Compiler and compatibility files never enter an archive.
- Repeated packaging preserves archive bytes, file identity, and timestamp when the target root is unchanged.
- Symlinks, non-regular files, empty roots, and invalid archive paths fail without publishing a partial archive.
