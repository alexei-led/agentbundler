# Native Verification

**Path**: `internal/artifact/nativeverify/` — the module's code is everything in this folder and transparent subfolders
**Parent**: `internal/artifact`
**Submodules**: none (leaf)

## Purpose

This module executes optional adapter-declared native validators after exact output comparison. Environment-dependent validation stays outside deterministic compilation.

## Functional Responsibilities

- Validate direct program/argv declarations and contained working directories.
- Execute without shell interpolation or interactive stdin.
- Capture bounded stdout/stderr and distinguish unavailable tools, start failure, nonzero exit, and truncation.
- Preserve the rule that native checks never affect generated bytes.

## Subdomain Classification

**Generic.** Bounded process execution is stable boundary infrastructure.

## Public Contract

<!-- contract: NativeCheck, Diagnostic, RelativePath — restated from internal/compiler/model/module.md -->

```text
NativeVerificationResult = { success: Boolean, diagnostics: [Diagnostic] }
run-native-checks([NativeCheck], output-root) -> NativeVerificationResult
```

Checks run sequentially. An absent working directory means the resolved output root; otherwise it is a contained existing directory below that root. Programs run directly with declared arguments, empty stdin, independently bounded stdout/stderr, and a minimal environment containing only the executable search path, isolated temporary home/config/cache/temp roots, and required Windows process variables. `MaxOutputBytesPerStream` is 32 KiB.

Production declarations are closed to official, offline, non-mutating validators:

```text
claude plugin validate --strict <generated plugin root>
grok plugin validate <generated plugin root>
```

Codex, Copilot, Cursor, and Pi do not declare production native checks. Their install/list/load/fire smokes are test-only, opt-in, and isolate HOME/config/cache roots.

## Integrations

- **Counterpart**: `internal/artifact`
  - **Direction**: parent invokes only after exact comparison reports no drift.
- **Counterpart**: `internal/compiler/model`
  - **Direction**: consumes adapter-declared `NativeCheck` values and emits model diagnostics.

## Constraints and Invariants

- No shell, argument interpolation, interactive stdin, ambient credentials/configuration, source-directory working path, or output mutation.
- Working-directory symlinks resolve below the resolved generated-output root or the check does not start.
- Check output is diagnostic evidence only; it is excluded from plans, provenance, and generated bytes.
- Compilation and rendering never inspect tool availability or installed versions.
- The runner does not run install, marketplace, trust, authentication, publishing, or configuration commands.

## Test Specification

- Shell metacharacters remain literal argv; ambient secrets/config variables are absent and isolated home/config/cache/temp roots exist.
- Invalid declarations and escaping/unavailable directories start no process.
- Missing tool, start failure, nonzero/signal, and truncation produce distinct deterministic diagnostics.
- Drift suppresses all native checks.
- Adapter declaration tests prove only Claude and Grok emit production checks.
